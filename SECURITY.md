# Безопасность и сообщения об уязвимостях

## Поддерживаемая версия

Поддерживается последняя версия `3.2.x`.

## Что считать уязвимостью

- обход red/yellow gate с получением `CLOSED`;
- использование stale evidence как current;
- изменение registry facts через user-editable observation;
- потеря хвоста или участка long-form документа;
- semantic mapping, позволяющий незаметно привязать чужой source unit;
- изменение immutable original без блокировки.

## Как сообщить

Не публикуйте чувствительные документы, detector screenshots или персональные
данные в публичном issue. Используйте GitHub Security Advisory репозитория,
если раскрытие требует приватного канала.

Для обычного воспроизводимого бага создайте issue с минимальным synthetic
fixture и ожидаемым результатом.

## Не является security guarantee

Palimpsest работает в локально редактируемом workspace. Он не защищает от
процесса, который может переписать весь state и исходный код. Для этого нужен
внешний trust anchor.
