# F4: оригинальность, цитирование и close paraphrase

## Цель

Не «обойти антиплагиат», а сделать происхождение текста корректным:

- чужая формулировка — цитата с атрибуцией;
- чужая идея — честная ссылка в требуемом стиле;
- общеизвестное — без искусственного цитирования;
- собственное объяснение — действительно заново выстроенная мысль.

## Четыре класса

1. **Exact quote.** Дословный фрагмент, оформленный как цитата.
2. **Close paraphrase.** Сохранён порядок, синтаксис или длинная лексическая
   цепочка источника; одной ссылки часто недостаточно.
3. **Idea-level dependence.** Формулировка новая, но идея или данные требуют
   атрибуции.
4. **Independent expression.** Автор самостоятельно выстроил объяснение на
   допустимой базе знаний и корректно сослался там, где нужно.

## Локальный экран

```bash
python3 scripts/source_overlap.py \
  --draft workspace/working.md \
  --source sources/a.md --source sources/b.md \
  --exclude-reference-list \
  --out workspace/overlap.json
```

Экран:

- исключает fenced code и явные цитаты из lexical-run поиска;
- по явному флагу исключает терминальный раздел `References`,
  `Bibliography`, `Список литературы` или `Библиографический список`, чтобы
  корректная библиографическая запись не выдавала ложный high-risk match;
- ищет совпадающие последовательности слов;
- помечает длинные runs и высокий процент абзаца;
- привязывает отчёт к SHA черновика и каждого источника.

Он не видит интернет, закрытые базы, семантическое копирование без общей лексики
и неправильную атрибуцию цитаты. Это честно перечисляется в `limitations`.

## Как исправлять

Для каждого high-risk фрагмента выбери одно:

- оформить точную цитату и добавить корректную ссылку;
- отложить источник, выписать только проверяемые тезисы, затем заново построить
  объяснение в логике текущего документа;
- объединить несколько источников в собственный аналитический вывод с
  атрибуцией;
- удалить фрагмент, если он не нужен или не подтверждён.

Нельзя:

- менять отдельные слова при сохранённом каркасе;
- дробить цитату, чтобы уменьшить процент;
- вставлять невидимые символы;
- переводить туда-обратно;
- убирать имя автора или ссылку;
- заявлять «плагиата нет» по локальному экрану.

## Цитаты

Проверить:

- текст цитаты точен;
- кавычки и отступ соответствуют стилю;
- источник существует и действительно содержит фрагмент;
- страница/секция указана, если стиль требует;
- эллипсис не меняет смысл;
- цитата не занимает непропорционально большой объём.

## Evidence

G6 требует:

1. `overlap_report` с `high_risk_count = 0` на текущем SHA;
2. `plagiarism_review` с source corpus, цитатами, close paraphrase,
   idea attribution и границей внешнего сервиса;
3. при наличии внешнего институционального отчёта — его дата, база, версия и
   ограничения отдельно.

Нулевой локальный high-risk count означает только отсутствие заданного lexical
run в supplied sources.
