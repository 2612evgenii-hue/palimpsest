# F3: факт-чек v3

## Claim ledger

Для каждого проверяемого утверждения:

| Поле | Содержание |
|---|---|
| ID/локация | адрес в текущем SHA |
| claim | точная формулировка |
| тип | число, дата, причинность, цитата, правовой/научный факт |
| требуемый источник | primary/official/review |
| найденный источник | URL/DOI/документ |
| дата публикации | дата источника |
| дата доступа | текущая дата |
| exact support | что именно подтверждает |
| status | supported / qualified / disputed / unsupported |
| resolution | сохранить, сузить, исправить, удалить, спросить |

## Иерархия источников

1. первичный документ, dataset, стандарт, закон, официальная статистика;
2. рецензируемая работа или официальный technical report;
3. систематический review;
4. качественный вторичный источник для контекста;
5. vendor/blog — только о собственном продукте или как lead.

Для текущих законов, цен, должностей, версий и правил всегда проверяй дату.

## Метод

1. Разложить сложный claim на атомарные.
2. Сформулировать, какое evidence опровергло бы claim.
3. Найти первичный источник.
4. Прочитать контекст, а не только snippet.
5. Проверить единицы, выборку, географию, период и определения.
6. Найти противоречащий источник, если stakes высоки.
7. Исправить только до уровня подтверждённого evidence.

## Цитаты и числа

Для цитаты проверить текст, автора, дату, страницу/секцию и отсутствие
искажающего эллипсиса.

Для числа проверить:

- numerator/denominator;
- единицу;
- базовый период;
- nominal/real;
- sample/population;
- оценка или наблюдение;
- актуальность.

## Нет evidence

Допустимые решения:

- убрать claim;
- сузить;
- превратить в явно обозначенную гипотезу;
- спросить пользователя;
- сохранить как limitation, если жанр допускает и пользователь принимает.

Недопустимо придумывать правдоподобную ссылку или оставлять уверенный claim.

## Связь с fidelity

Фактологическая правка меняет исходный смысл намеренно. В semantic review она
должна быть отмечена как разрешённое изменение с источником; иначе
fidelity-конфликт останется необъяснённым.
