# Диагностика AI-like regularity v3

## Не список запретных слов

Один оборот не доказывает машинность. Ищи кластеры и функцию:

- регулярность повторяется;
- она не требуется жанром;
- она делает ход мысли предсказуемым или пустым;
- локальная правка может улучшить текст без смысловой потери.

## Основные механизмы

### Риторическая избыточность

- тезис повторяется в начале и конце каждого абзаца;
- вывод пересказывает уже сказанное;
- метафраза описывает структуру вместо содержания;
- важность заявляется, но не показывается.

### Метроном

- одинаковая длина предложений;
- повторяющийся `claim → explanation → example → summary`;
- абзацы-близнецы;
- одинаковые финалы;
- серии симметричных триад.

### Служебная перегрузка

- штабели `however / moreover / therefore`;
- каждый вывод объявлен заранее;
- hedges и boosters применяются равномерно;
- канцелярские nominalizations вытесняют действие.

### Абстрактность

- существительные без агента, механизма или наблюдаемого следствия;
- универсальные преимущества без условий;
- «evidence-based», «robust», «comprehensive» без конкретного evidence;
- пример заменён категорией.

### Стерильная гладкость

- нет локального приоритета;
- все возражения уравновешены одинаково;
- каждый абзац автономен и не зависит от предыдущего;
- текст не делает выбора.

### Артефакты генерации

- placeholders, системные фразы, шаблонные заголовки;
- несуществующие цитаты/ссылки;
- внезапная смена языка/лица;
- повтор формулировки запроса.

## Жанровые исключения

Не ломай:

- определения и спецификации ради «живости»;
- обязательные headings;
- юридические повторения, обеспечивающие область действия;
- методологические перечисления;
- accessibility/plain-language требования;
- citation conventions.

## Severity

- `P0`: фактическая/семантическая/генеративная ошибка;
- `P1`: сильный кластер, влияющий на доверие или ясность;
- `P2`: локальная шаблонность;
- `P3`: вкусовое наблюдение; само по себе не даёт права на правку.

## Инструмент

```bash
python3 scripts/pattern_scan.py FILE --min-sev P1
```

Сканер — high-recall screen. Каждая находка подтверждается чтением контекста.
Если правило не объясняет вред, не применяй его.
