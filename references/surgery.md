# Хирургия v3

Выбирай приём по механизму, а не по желанию «переписать покрасивее».

## M-DEL — удалить лишнее

- `M-DEL-1`: убрать повтор тезиса;
- `M-DEL-2`: убрать метафразу, если структура и так ясна;
- `M-DEL-3`: убрать пустой booster/hedge;
- `M-DEL-4`: убрать генеративный артефакт.

Проверка: не исчезло ли обязательство, оговорка или переход логики.

## M-CONC — вернуть конкретику

- `M-CONC-1`: назвать агента действия;
- `M-CONC-2`: заменить категорию наблюдаемым механизмом;
- `M-CONC-3`: привязать преимущество к условию;
- `M-CONC-4`: вернуть пример, уже содержащийся в исходнике/источнике.

Не изобретай пример или данные.

## M-RHY — ритм

- `M-RHY-1`: объединить предложения, искусственно раздробленные одинаково;
- `M-RHY-2`: разделить перегруженное предложение по реальному повороту мысли;
- `M-RHY-3`: перенести акцент в сильную позицию;
- `M-RHY-4`: убрать одинаковые начала/финалы соседних предложений.

Ритм должен следовать функции, а не случайному чередованию длин.

## M-LOG — логика

- `M-LOG-1`: поставить основание рядом с утверждением;
- `M-LOG-2`: отделить корреляцию от причинности;
- `M-LOG-3`: вернуть область применимости;
- `M-LOG-4`: превратить декоративный переход в содержательный;
- `M-LOG-5`: сделать возражение реальным, а не церемониальным.

После каждого M-LOG нужен semantic review конкретной локации.

## M-STRUCT — структура

- `M-STRUCT-1`: слить абзацы-близнецы;
- `M-STRUCT-2`: разделить абзац с двумя функциями;
- `M-STRUCT-3`: убрать повторный conclusion;
- `M-STRUCT-4`: изменить порядок блоков по зависимости;
- `M-STRUCT-5`: сохранить обязательный heading, но перестроить внутренний ход.

Не менять структуру раздела только ради detector score.

## M-VOICE — почерк

- `M-VOICE-1`: импортировать тип оговорки;
- `M-VOICE-2`: адаптировать степень прямоты;
- `M-VOICE-3`: восстановить характерный способ конкретизации;
- `M-VOICE-4`: изменить способ закрытия абзаца;
- `M-VOICE-5`: удалить карикатурно повторённый quirk.
- `M-VOICE-6`: сохранить уровень английского, отменив неоправданное усложнение
  или упрощение.

Фраза из внешнего reference не вставляется дословно. В
`source_as_reference` каждое M-VOICE требует доказать, почему сохранение
исходной формы было невозможно; «сделать профессиональнее» само по себе не
основание повышать learner level.

## M-FACT — факт

- `M-FACT-1`: исправить по первичному источнику;
- `M-FACT-2`: сузить claim до подтверждённого;
- `M-FACT-3`: явно квалифицировать неопределённость;
- `M-FACT-4`: удалить неподтверждённый claim;
- `M-FACT-5`: спросить пользователя, если решение меняет результат.

## M-ATTR — атрибуция

- `M-ATTR-1`: оформить exact quote;
- `M-ATTR-2`: заново вывести объяснение из идеи;
- `M-ATTR-3`: синтезировать несколько источников;
- `M-ATTR-4`: добавить требуемую ссылку;
- `M-ATTR-5`: удалить close paraphrase, не несущий уникальной функции.

## Anti-swap

Не менять один штамп на другой:

- `it is important to note` → `notably`;
- `plays a crucial role` → `is pivotal`;
- три прилагательных → другие три прилагательных;
- одинаковые короткие/длинные предложения по шаблону.

После правки спроси: изменился ли механизм или только поверхность?

## Move

Один move может включать связанный пакет локальных изменений:

```bash
python3 scripts/state.py --state workspace/STATE.json move \
  --id M07 --span "S004:P2-P3" \
  --hypothesis "M-DEL-1 + M-LOG-1 remove duplicated summary and place evidence beside its claim."
```

`outcome` заполняется после проверки. Не требуется отдельный move для каждой
запятой, но массовые несвязанные изменения нельзя прятать под одним ID.
