# Опциональная делегация

Palimpsest не требует субагентов. Используй их только если пользователь явно
просит делегацию/параллельную работу и среда это разрешает.

## Границы

- master editor владеет source of truth, state и финальной сверкой;
- один агент — один независимый артефакт или набор сегментов;
- никто не закрывает гейт вручную;
- никто не редактирует чужой сегмент;
- Ductus-аналитик получает references, но не рабочий текст, если нужно избежать
  подгонки профиля;
- red-pen получает чистый current + original, но не диагноз, чтобы не повторять
  ожидания мастера.

## Подходящие задачи

- независимая диагностика patterns;
- Ductus по reference corpus;
- claim ledger по заранее разделённым claims;
- blind semantic comparison;
- анализ отдельного неперекрывающегося longform-сегмента.

## Неподходящие задачи

- дать нескольким агентам переписать один и тот же абзац;
- поручить субагенту пользовательское решение;
- собирать detector scores без общей capability policy;
- принять артефакт по фразе «всё проверено».

## Brief

Каждое поручение содержит:

- точные входные файлы и SHA;
- разрешённые локации;
- цель и запрещённые действия;
- формат результата;
- критерии evidence;
- предупреждение, что другие участники работают параллельно и их изменения
  нельзя откатывать.

Мастер проверяет артефакт и регистрирует его только после собственной сверки.
