# Фикстуры: что это и чем это не является

Файлы нужны `selftest.py`, чтобы проверять **чувствительность инструментов**: ловит ли сканер
штампы, видит ли `fidelity_check` потерю числа, растёт ли `minimality` при переписывании.
Это лабораторные образцы, а не портфолио.

| Файл | Роль | Чем полезен |
|---|---|---|
| `ai-ru.md` | типичный машинный текст (RU) | плотность штампов P0/P1, метроном, номинализация |
| `ai-en.md` | типичный машинный текст (EN) | англоязычные шаблоны, `not just X but Y`, `landscape` |
| `reference-ru.md` | живой человеческий текст (RU) | эталон почерка для `style_distance`, а также тест E1 «не портить живое» |
| `edited-ru.md` | сильная переработка `ai-ru.md` | нарочно **вне бюджета**: на нём проверяется, что `minimality` ругается |
| `edited-minimal-ru.md` | сдержанная правка `ai-ru.md` | штампы сняты (AI-smell 93.9 → 11.6), но почерк автора **не** сведён |
| `annotated-ru.md` | корректная разметка | парсер, статусы, `--check-clean` |
| `annotated-broken-ru.md` | битая разметка | валидатор ловит незакрытые и повреждённые марки |

## Честно про `edited-minimal-ru.md`

Это учебный пример, а не образец идеального эдита. Замеры на нём:

```
AI-smell: 93.9 → 11.6      P0: было → 0
distance до reference-ru:  74.0 → 68.2   (всё ещё «другой автор»)
изменено слов: 29.3%       два абзаца выше абзацного бюджета
```

То есть машинные штампы сняты, а почерк конкретного автора не перенят: текст стал
нейтрально-чистым. Ровно этот сценарий доктрина называет **bland-clean** и считает провалом
(правило 13). Фикстура сохранена именно потому, что показывает разрыв между «не пахнет ИИ»
и «похоже на автора» — снижение AI-smell не даёт сближения почерка автоматически.

Хочешь фикстуру-эталон? Её нельзя сгенерировать скриптом: нужен настоящий отредактированный
текст с реальными замерами детекторов. Появится живой кейс — положи его рядом как
`case-<дата>/` вместе с `REPORT.md`, и тогда на нём можно будет калибровать пороги.
