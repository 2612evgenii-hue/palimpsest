# История изменений

Все заметные изменения проекта документируются в этом файле.

## 3.2.0 — 2026-07-30

### Добавлено

- immutable original SHA и source-language binding;
- точные semantic evidence offsets;
- `READY_WITH_LIMITS` для внешнего решения yellow gates;
- plateau schema v2 с digest-bound moves и mechanism diversity;
- строгий English-level feature envelope;
- reliable-sample policy для style distance;
- гетерогенный synthetic long-form stress;
- 83-тестовый combined selftest.

### Исправлено

- русский текст больше нельзя переобъявить как English;
- `authorized_change` с чужим excerpt не принимается;
- локальная цитата не закрывает yellow state;
- synonym-only candidates не образуют plateau;
- one-band English-level drift блокируется;
- документация больше не называет synthetic stress book-scale validation.

### Ограничения

- detector captures и local state не являются криптографическими evidence;
- EN detector corpus остаётся pilot 3+3;
- RU detector workflow остаётся provisional.
